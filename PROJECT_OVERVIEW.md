# ClientFlow Project Overview

## Product
ClientFlow is a fictional customer-management platform for small and medium-sized businesses.

## Main goal
Help businesses manage customer information, follow up on leads, track sales activity, and monitor customer relationships from one place.

## Current status
The product is in active development. The team is preparing a new release focused on reporting, mobile usability, and customer communication.

## Current priorities
- Improve dashboard performance.
- Make the mobile experience easier to use.
- Improve customer reporting.
- Reduce recurring notification problems.
- Simplify onboarding.
