# Customer Support Notes

## Recent patterns

Customer Success has noticed three recurring themes:

1. Customers want better reporting.
2. Mobile users want easier navigation.
3. Performance problems become more noticeable as customer data grows.

## Support recommendation

Before adding many new features, the team should consider improving the reliability and usability of the existing product.

## Open question

Should the next release prioritize new reporting capabilities or address performance and mobile usability first?

The product manager wants a recommendation supported by the available customer and issue information.
